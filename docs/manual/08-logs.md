# 操作日志

> 仅 **管理员** 可访问此页面。记录系统内高敏感操作的审计追踪。

## 功能概述

操作日志由服务端自动写入，主要覆盖：

| 类别 | 操作类型 |
| -------- | ---- |
| 数据备份 | 导出/恢复数据库、导出/恢复附件、删除用户附件目录 |
| 用户管理 | 创建/更新/删除用户、更新教师负责班级 |
| 系统设置 | 审核设置、系统设置、成就上传限制 |
| 认证 | 用户注册、登录失败、修改密码 |
| 审核流程 | 提交/撤销/自动通过/通过/驳回（个人信息与成就） |
| 直接改数据 | 绕过审核直接更新档案或成就（创建/更新/删除） |
| 数据导出 | 导出学生 Excel、导出学生 PDF（教师/管理员/干部） |

## 页面结构

管理员在侧边栏导航中点击「操作日志」进入。

### 搜索

输入用户名、操作类型或详情关键字进行筛选，支持模糊匹配。

### 日志列表

每条日志包含：时间、用户、操作（中文标签）、详情、IP。

### 分页

列表支持分页浏览，默认每页 20 条。

## 注意事项

- 操作日志为只读，不可删除或修改
- 登录成功记录见「设置 → 登录历史」（按用户查看，保留 30 天）
- 导出类事件由服务端校验角色后写入，不可伪造
