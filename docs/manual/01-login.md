# 登录与注册

## 登录

未登录用户会进入登录页面。

![登录页面](/images/login登录页面.png)

### 输入凭证

| 字段                     | 说明                          |
| ------------------------ | ----------------------------- |
| **用户名(一般就用学号)** | 4–32 位英文字母、数字或下划线 |
| **密码**                 | 账号密码                      |

登录后默认跳转到 `我的信息(myinfos)` 界面。

### 学生首次改密（管理员创建账号）

管理员在后台创建的学生账号，或管理员重置密码后，账号会标记为**须改密**。此类学生登录后不会进入主界面，而是跳转到 **`/change-password`** 专属页，必须修改密码后才能使用系统。

- 自助注册的学生（自己设置密码）**不会**进入强制改密流程。
- 是否须改密由数据库字段 `must_change_password` 决定，**与登录历史条数无关**（退出后再次登录仍会要求改密，直到改密成功）。

## 注册

在登录页面点击「没有账号？去注册」进入注册页面。

![注册页面](/images/register注册页面.png)

> 管理员可以在 `后台管理` > `其他设置` 里面关闭/开启注册功能.

### 输入信息

| 字段     | 说明                                        |
| -------- | ------------------------------------------- |
| **名字** | 姓名，用于界面展示                          |
| **学号** | 4–32 位英文字母、数字或下划线，唯一不可重复 |
| **密码** | 建议包含字母与数字                          |

> 注册默认是"学生角色"

有四种角色，对应不同的访问权限：

| 角色       | 说明         | 可访问页面                     |
| ---------- | ------------ | ------------------------------ |
| **学生**   | 普通学生账号 | 我的信息、个人成果、通知、设置 |
| **班干部** | 班级审核权限 | 学生权限 + 班级审核            |
| **教师**   | 查看学生档案 | 班干部权限 + 学生信息          |
| **管理员** | 系统后台管理 | 全部页面                       |

### 注册成功

注册成功后跳转到登录页登录。

若无需强制改密，首次登录会提示先填写[我的信息](./02-myinfo.md)。
